# Mehria Arshad Portfolio — React + Tailwind CSS + React Router

## Run the project

1. Install Node.js if it is not installed.
2. Open this folder in VS Code.
3. Open the terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Routes

- `/` — Home
- `/about` — About
- `/work` — Work
- `/skills` — Skills
- `/contact` — Contact

## Where to edit

- `src/components/Navbar.jsx` — responsive navigation and React Router links
- `src/components/Footer.jsx` — footer
- `src/pages/` — each page
- `src/index.css` — Tailwind import and a few global styles
- `public/images/` — your original portfolio images

The project uses Tailwind CSS v4 through the Vite plugin. Navigation uses `Link`, `NavLink`, `Routes`, and `Route` from `react-router-dom`.

Your original project folders for Creative Studio, Mood App, and More Creative were not included in the uploaded ZIP, so their links are placeholders until you copy those folders into `public/projects/`.
